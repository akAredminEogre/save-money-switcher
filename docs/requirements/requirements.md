## 🟨 参考ゲーム『賞金先渡しクイズ SAVE MONEY』ルール要点（出典付き・確定仕様ではない参考）

> 出典: [Wikipedia『賞金先渡しクイズ SAVE MONEY』](https://ja.wikipedia.org/wiki/賞金先渡しクイズ_SAVE_MONEY)（2026-07-25 取得）。以下は同ゲームの理解のための要点で、本プロダクトの確定仕様ではない（家族版へどう翻案するかは壁打ちで詰める）。

- **賞金先渡し（コア演出）**: 「人は得たものを失うのが一番辛い」がテーマ。ゲーム開始時に各解答者へ賞金を**先に配分**（レギュラー1人50万円／スペシャル100万円）。
- **出題形式**: **すべて 0〜100 の数値で答える問題**。手元の4ボタン（+1／−1／+10／−10）で数値を決定。価格予想・商品数・統計数値など。
- **減額の仕組み**: 正解との**誤差1につき1万円ずつ没収**（誤差5なら5万円喪失）。全額喪失で脱落。
- **ピタリ賞**: 完全正解（誤差0）で他の解答者から**10万円を横取り**。
- **勝敗**: 全問終了時（スペシャル10問／レギュラー5問）に**残金が最多の1名が賞金獲得**。
- **競技形態**: 基本は個人戦（複数名）。特別編で1人挑戦やペア戦の実施例あり。
- **題材と「節約」の関係**: Wikipedia には節約・買い物との**直接的関連の記載は不明**（数値当て全般の番組）。

**🟨 本プロダクトへの含意（軍師メモ・未確定）**:
- SAVE MONEY の「0〜100 を手元ボタンで入力」は、確定済みの**第二要件（解答者スマホで数値入力）と自然に一致**（スマホUIに +1/−1/+10/−10 ボタンを置ける）。論点11（入力仕様）は「0〜100 の整数」で具体化する下地になる。
- 「賞金先渡し＋誤差で減額＋残金最多勝利＋ピタリ賞横取り」が論点3（得点方式）・論点6（演出）を具体化する骨格になりうる。

    - 🟨 第二要件は「数字を入力」。整数のみか、小数・マイナス・桁数上限をどうするか。
    - 選択肢: (A) 整数のみ／(B) 小数を許可／(C) マイナスを許可／(D) 上記の組合せ。桁数上限の要否も。
    - 問い: 「回答は**整数のみ**でよいですか（小数・マイナスの要否）。最大桁数の想定はありますか？（題材が金額なら桁数が大きくなり得ます）」
